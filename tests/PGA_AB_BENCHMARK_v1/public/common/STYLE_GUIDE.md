# 公共风格与表达条件

这是本实验新制作的现场维修/救援设备像素资产族。它只定义本轮任务方向，不是商业级质量标杆，也不是要求复刻某张目标图。

采用硬边、无抗锯齿像素表达。主结构以冷灰金属为主，小面积信号色承担功能重点；需要暖琥珀色时以任务说明为准。色阶应从暗部、主体、受光到少量高光形成关系。体积要服务于形体，不靠随机噪点。局部新颜色允许使用，不要求完全拘泥于起点色值。

原生尺寸和固定4倍最近邻预览都要看。统一使用深背景#202028与浅背景#d6d8dc。不能只提交放大美化展示板；不可添加灯光、模糊、抗锯齿或额外图像滤镜来抬高观感。公共色阶仅为可用起点，不是评分答案。

先处理本任务的主要可见问题，然后检查整体和被保护的优点。任务并不要求永远从轮廓开始，也不鼓励机械增加细节。可以保留简洁表现。

`style-swatches.png` 只是共有色阶条，不是成图参考。每项TASK.md与白色允许区规定了可改范围。技术合规、美术目标、工具使用合规是三个分开判断的维度。
