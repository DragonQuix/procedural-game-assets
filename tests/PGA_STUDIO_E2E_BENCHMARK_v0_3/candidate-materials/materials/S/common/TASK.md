# Task S：能量转接模块

把这枚小型游戏道具的占位中心改成能清楚表达“把能量从一个端口传给另一个端口”的功能结构或符号。
不要写文字、字母或数字。可以用端口、流向、连接、汇聚等视觉关系自行设计，
不要求某一种箭头、闪电或单一标记，也没有答案图。
保持外壳设计语言、`node.case`、`node.anchor`、保护轮廓与 anchor。
`node.mark.a` 至 `node.mark.e` 是可改造的中心图形部件，不是规定答案的笔画。

硬合同见 `task-contract.json`：只在中心 Region P1（x=14,y=14,w=36,h=36）内改动，
alpha 外轮廓完全不变，mark 部件支持像素并集为 70–650，总修改至少 40 像素。
中心语义、无文字、视觉层级、清晰度和与外壳的协调由盲评确认。
