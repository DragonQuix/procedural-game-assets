# Task M：偏置夹紧组件

这是一套带开口夹体、压力垫、丝杆与横柄的机器组件。请让工作部件显出金属体积，
并形成工作面优先、横柄及饰件次要的明度层级。可选择不同光照概括与色阶组织，不指定唯一材质答案。
Node `node.jaw`、`node.spindle`、`node.pad` 是工作部件；`node.handle` 是 secondary。
保护轮廓锚点及两个螺栓，anchor 不变；不要通过大幅改形替代材质任务。

硬合同见 `task-contract.json`：外轮廓差分最多 24 像素，每部件像素只可在其起点包围盒
扩张 1 像素的 ownership 范围内出现；工作部件至少使用 3 种不透明颜色。
全图最多 20 色，亮度 Y=0.2126R+0.7152G+0.0722B 在 20–245 内，总修改至少 80 像素。
这些只是可验证边界。金属可读性、主次层级与整体一致性由独立视觉评审判断。
