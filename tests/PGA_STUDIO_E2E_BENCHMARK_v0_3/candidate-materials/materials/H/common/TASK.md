# Task H：重力稳定器

这是一台放在地面的科幻重力稳定器。起点的几个亮部争夺注意力，机身比例普通。
请让主体看起来稳定、有重量，并让 Node `node.display` 成为清楚的焦点。
必须明显改造外轮廓，不只是换色。造型、明暗分配与附件比例由你设计；没有答案图。
保留底座 Region P1（合同中的 protectedRegions）、`node.base`、`node.emblem` 和 anchor。

硬合同见 `task-contract.json`：轮廓 alpha 差分 60–560 像素、不透明面积 700–2300，
总修改至少 40 像素；其余尺寸、调色板边界和保护共同适用。这些是可行范围，不是目标宽高。
视觉验收看重量感、display 焦点、结构连贯和干净边缘；机械通过不自动代表视觉完成。
