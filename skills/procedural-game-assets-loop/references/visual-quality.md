# 循环版视觉范围与准则

本文件给总控、builder 和揭盲后的 visual。盲比阶段仅发盲比任务书与匿名图。
美学依据沿用 [视觉质量标准](../assets/toolkit/docs/visual-quality.md) 的质量标尺、整体美学、
原创差异及公平对照准则；该文档末尾的普通版轻量验收不适用于本入口，循环版必须执行双批次。

## 范围与证据

每个约定资产/动作或集合在 `visualPolicy.scopes` 中有可核对的范围。整体美学始终另评，
不能只把所有资产合成一张最佳海报便声称覆盖。每个范围都具有四项基础维度：

| dimension | 判断内容 | 必需视图 |
|---|---|---|
| `design` | 轮廓、比例、姿态、体块、负空间与功能/气质的设计组织 | `display` |
| `hierarchy` | 色彩、明度、焦点、疏密、留白和视觉主次 | `display` |
| `finish` | 边缘、像素簇或线条、材质概括、光影和细节完成度 | `native` |
| `usability` | 目标尺寸及约定背景下的识别、稳定性和信息表达 | `display`，需要时加 `context` |

`native` 为原生尺寸，`display` 为实际显示尺寸。若相同可以引用同一文件；放大只辅助
定位，不能替代正常尺寸。按范围 `kind` 追加维度和视图：

| kind | 范围示例 | 追加维度 / 视图 |
|---|---|---|
| `asset` | 单个角色、道具、图标、植被、静态资产 | 无，按类型填写基础维度标准 |
| `series` | 角色族、方向组、图标集或整套资产 | `cohesion` / `overview`：风格、尺度、质量一致性 |
| `animation` | 一组动作及其关键过渡 | `motion` / `playback`：意图、重量、节奏、接地与跨帧一致性 |
| `effect` | 弹体、爆炸、技能特效 | `motion` / `playback`：形态演化、强弱、时序与遮挡 |
| `tilemap` | 可拼接地块、组合场景 | `tiling` / `assembly`：接缝、重复痕迹、边界过渡与场景层次 |

同时涉及多个类型时分成多个范围，共用证据允许，例如逐项动作加一个全套总览范围。
单范围可有多个同类视图，所有登记视图必须在 `coverage` 中有引用；不适用的类型不新增。
一张图包含全部范围不等于已经看完，必须实际识别各资产和关键状态。采集者核对合同内容
与范围矩阵是否完整；脚本不能发现未被写进宪章的漏项，也不能证明动画真的播放过。

## 等级与独立要求

`basis=reference` 比较等效视觉功能和设计控制力，不逐区域要求相同内容。每项输出
`qualityRelation`：`BELOW / ON_PAR / ABOVE / NOT_COMPARABLE`，准出只接受 `ON_PAR / ABOVE`。
`NOT_COMPARABLE` 表示材料或条件不足，不是负面美术结论。

`basis=requirement` 按冻结的任务要求输出 `status=PASS / NOT_YET / UNVERIFIED`，不填
`qualityRelation`。例如静态标杆支持角色形色比较，但跑步要按独立动作要求和播放证据验收。
缺动画参考不自动阻塞，缺实际播放或必要要求不能通过。约定系列与地块按同样原则处理。

整体 `holistic` 单独判断完整资产/整套的吸引力、气质、协调与专业完成度，说明与标杆的
档次关系；参考盲区按独立要求验收，不扩大“同级”结论的覆盖。`aestheticVerdict` 与
`qualityRelation` 均须明确，不能让高分或若干局部亮点抵消明显整体差距。

WOW 意味达到对齐的高质量而非要求超越标杆、越来越华丽或永无瑕疵。个人偏好可以不同；
简洁、色彩或造型差异本身不扣级，也不强迫设计为显得原创而刻意变化。用户明确约束另外
核查，不能从参考自动继承身份。分数可选且仅作诊断，不是平均放行或低分否决的机器条件。

## 可执行的反馈

先指出现象和关系，再说明对观感/使用的影响、依据、严重度与复查办法。整体问题可引用
整个主体或整套画面，不强拆成像素坐标；“不够惊艳”或“我更喜欢红色”不是有效否决。
说明必须改善的效果，不要求 builder 采用与标杆相同的解法；改善次序由等级差距决定。
已达标的设计选择不列为缺陷，更高追求只作可选建议，不成为继续循环的隐含条件。
