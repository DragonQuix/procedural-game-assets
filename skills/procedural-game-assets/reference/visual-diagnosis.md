# 视觉诊断参考

诊断顺序固定：**轮廓与比例 → 动作和附件 → 色阶与可读性 → 纹理与特效**。
每轮只修一类问题，保留原图、修改图与问题描述。

## 画廊视图对照

`node bin/pga.mjs gallery --dir <导出目录> --port 47840`：

- 1 倍原生尺寸 + 4 倍（带像素网格）：4 倍看得清不代表 1 倍可读，两者都要看。
- 变体：原图 / 镜像 / 白闪 / 剪影 / 灰度。剪影查轮廓，灰度查明度层次。
- 背景：深色 / 浅色 / 棋盘 / 夜间场景 / 日间场景。危险物与角色至少在
  夜间场景下单独验收一次。
- 叠加：锚点十字、附件点（枪口红点）、包围盒。
- 对比视图：选"对比"资产，同帧 ID 或同位置并排，同视图设置。
- URL 全部视图状态可复现：`?asset&frame&zoom&bg&variant&clip&compare`。

## 植入故障实景（examples/faults/，均已验证工具能暴露）

1. **被裁掉的枪口**（`clipped-muzzle.mjs`）：枪长超出帧宽。
   暴露：裁剪诊断计数、muzzle 坐标超出帧宽、枪管在右缘截断。
   修法：放大帧或缩短枪长；烘焙默认 error 本应先拦截。
2. **错误镜像附件点**（`bad-mirror.mjs`）：镜像帧附件点没随 `W-x` 变换。
   暴露：附件点红点明显脱离枪管。修法：用 `bake/variants.js` 的
   `flipVariant` 联动变换，不手工拼帧。
3. **颜色过近的敌弹**（`bullet-contrast.mjs`）：暗红敌弹在夜背景上不可读。
   暴露：夜间场景背景 + 与玩家弹的对比视图。修法：提高明度差、换色相。
4. **滑步动作**（`sliding-run.mjs`）：跑步 6 帧全部站立腿姿。
   暴露：剪辑连续条 6 帧重复，与正常跑步条（相位差+身体起伏）对照。
   修法：用 `runLegs` 相位表；跑步必看连续条与播放。

## 评审量表（辅助）

每项 0/1/2：0 不可用，1 可用但有明显问题，2 达到样例目标。
建议总分 ≥10/12 且无 0 分才批量派生。分数是评审记录，不是美学证明；
像素哈希正确不表示好看，视觉好看也不许忽略附件坐标错误。
