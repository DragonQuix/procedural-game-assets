# 当前实施路线（范围校正版 v2）

日期：2026-09-26。本文件是范围校正后的现行计划，取代原方案中
"Godot 为首版必做"的排序；原方案在只读的原项目中，作为历史依据保留

## 目标

让其他 Agent 借助工具包、模板和技能，制作类似原项目的**完整网页游戏**，
而不只是生成跨引擎美术资产。

## 产品边界

- **A 程序化资产核心**：像素绘制、ASCII、姿态、配方、锚点/附件点、审图、测试。已完成（P0–P5），持续维护。
- **B 网页优先接入**（ADR-0004）：启动烘焙 + Canvas 缓存为默认路径；离线 PNG 图集 + manifest 为可选部署。两条路径共享烘焙核心。
- **C 轻量 Canvas 网页游戏模板**（ADR-0005）：固定步长循环、输入、暂停/重启、动画、镜头、AABB 碰撞与一种交互、层序与命中反馈、固定种子与 step/state 测试接口、本地预览。不做通用引擎。
- **D 技能**：主用途="用工具包与模板制作网页游戏"；Godot 为按需读取的可选适配。
- **E 资产循环特别版**（2026-09-28，ADR-0006）：独立入口 `procedural-game-assets-loop`，
  对照标杆生产 2D 程序化资产，独立盲审与交付审计、同候选双批次 WOW；默认无预算
  上限。普通游戏入口不变。方法来源与检索边界见 `research/asset-loop-landscape.md`。
- **普通版视觉质量升级**（2026-09-28，0.4.1）：按 `visual-quality.md` 检查整体美学、
  标杆同级与完整游戏画面，允许原创设计；无标杆按独立目标验收。不引入循环版的
  独立盲审、双批次或无限迭代。
- **循环版视觉合同升级**（2026-09-28，0.5.0，ADR-0007）：新任务采用 `pga-loop/2`，
  整体美学、质量同级、范围/视图覆盖与明确约束独立校验；不奖励外观复制，视觉分数仅诊断。
  提供旧合同只读验证器，不继承旧 WOW。普通版发行保持 0.4.1，各宿主安装另行授权升级。
- **F PGA Studio**（2026-09-28，ADR-0008–0011，0.6.0）：面向视觉 agent 的创作控制层。
  可编辑 JSON 文档经共享烘焙核心渲染、编辑事务（候选/保护/恢复/幂等）、预览播放并导出既有资产格式；
  已覆盖静态道具（/1、/2）与一个角色（锈爪跨帧修改）。M0–M6 完成记录见 `verification.md` S1–S6、
  `plans/agent-studio.md`；agent 合同见 `studio-cli.md`。不改变普通/循环版入口与准出规则；
  循环版载荷不随动（保持 0.5.0），用户级安装升级另行授权。

## 首版验收（v2）

干净目录中，仅凭发行工具包、模板和技能，制作一个可玩网页游戏切片：

- 与默认示例有明显区别的新角色及场景；
- 移动、一种交互、明确的成功或失败状态；
- 动画与视觉反馈（受击白闪/粒子等至少其一）；
- 浏览器实际画面与操作验证（截图留证）；
- 自动化测试及可复现的运行步骤。

不能仅以图集导出、画廊正常或 Godot 导入成功宣布完成。
无独立 Agent 授权时，只记录当前实施者的干净目录复用结果，不冒充独立试验。

## 冻结项

- Godot 增强（编辑器集成、更多样例）：暂停，非首版阻塞。
- 音频模块：旧技能保留参考（reference/audio.md），不升级为工具包模块。
- Unity 适配、网络服务：不做。
