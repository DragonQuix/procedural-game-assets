# ADR-0002：统一几何坐标契约

日期：2026-09-26。状态：已接受。

## 背景

来源项目混用多种坐标约定：ASCII `marks` 是像素索引；骨架 `p.marks.head` 是相对锚点偏移；锚点是像素边界坐标且镜像用 `w - ax`（点）而像素镜像用 `w - 1 - i`（索引）；角色帧硬编码 38×46 并静默裁剪越界绘制。移植时这是误差与静默错误的主要来源。

## 决定

1. **像素边界坐标系**：帧左上角 `(0,0)`，x 向右、y 向下；像素 `(i,j)` 覆盖 `[i, i+1)×[j, j+1)`，其中心为 `(i+0.5, j+0.5)`。几何点允许小数，栅格化时按各原语明确规则取整；负数坐标禁止用 `|0` 冒充 `Math.floor`。
2. **同坐标系**：`anchor`、`attachments`、可选 `sockets` 均为帧内像素边界坐标。相对偏移一律 `attachment - anchor`。
3. **镜像**：点变换 `(x,y) → (W-x, y)`；像素索引变换 `i → W-1-i`。两者不得混用。
4. **旋转**：顺时针 90° 点变换 `(x,y) → (H-y, x)`，新尺寸 `(H,W)`；`rotate90(t)` 连续应用 4 次恒等。
5. **padding**：画布四周补 `p` 像素时，所有锚点与附件点 `+p` 平移。
6. **marks**：ASCII 标记字符记录的是像素中心；需要边界语义时换算 `index + 0.5`。脚底等边界位置使用显式 `anchor` 字段，不靠隐式猜测。
7. **裁剪策略**：绘制器支持 `error` / `warn` / `allow`；配方烘焙默认 `error`，有意裁剪必须显式声明。诊断记录每次越界尝试，可定位到帧与调用。
8. **历史兼容**：原配方相对脚底的整数枪口坐标经显式转换函数迁移；转换导致的视觉差异须标注并批准，不为新约定静默移动历史素材。

## 后果

- 全部几何变换（镜像、旋转、padding、描边扩边）对锚点/附件点的联动由共享函数完成并逐项测试。
- 帧尺寸不再硬编码；配方声明帧约束，尺寸不足产生诊断而非静默裁掉。

## 备选方案（已否决）

- 每个消费引擎各自补偏移：同一错误会在多处反复修复（见方案 §9）。
- 保留"相对脚底"第二坐标系：来源项目已证明两种坐标混用难以审计。
