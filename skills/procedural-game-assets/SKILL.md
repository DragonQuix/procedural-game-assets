# 程序化游戏资产（工具包版）

本技能附带**可运行工具包**（`assets/toolkit/`，Node 22+，ES Module）：像素核心、
姿态求解、五类配方、图集导出、审图画廊、Canvas/Godot 消费样例。
**优先使用工具包并修改配方数据；不要照着本文档重写绘制器或导出器。**

## 快速入口

```powershell
cd <技能目录>/assets/toolkit
npm ci                      # 仅 pngjs 一个运行时依赖（锁版本）
node --test                 # 先确认工具包在你机器上全绿
node bin/pga.mjs validate examples/recipes/rustclaw.mjs
node bin/pga.mjs export  examples/recipes/rustclaw.mjs --out work/out
node bin/pga.mjs gallery --dir work/out --port 47840   # http://127.0.0.1:47840/
```

四类命令：`validate`（配方校验，非零退出=失败）、`bake`（独立帧 JSON + 可选 BMP）、
`export`（PNG 图集 + 版本化 manifest）、`gallery`（审图服务器，只绑回环）。
输出目录有覆盖保护：非空且无 `.pga.json` 标记时拒绝写入。

## 关键约束（违反即返工）

1. **先跑通再创作**：`node --test` 必须通过；之后只做"改配方数据"级别的工作。
   觉得核心缺功能时，先记录理由再改核心，并把原因写进交接。
2. **坐标契约**：锚点/附件点是帧内像素边界坐标（左上原点，y 向下）；
   相对偏移一律 `attachment - anchor`；镜像点 `W-x` 与镜像像素 `W-1-i` 不是一回事；
   详见 `assets/toolkit/docs/adr/0002-coordinate-contract.md`。
3. **帧约束显式**：内容越界默认烘焙失败。不要靠 `clip:'warn'` 掩盖——
   先放大帧或改数据；只有兼容历史素材时才显式声明显式裁剪并写明理由。
4. **确定性**：同配方同种子同输出。纹理用世界坐标哈希/种子随机源，
   禁止 `Math.random()` 进配方。静态纹理预烘焙，运行时不得逐帧重新生成。
5. **同源**：画廊与导出共享同一烘焙实现；PNG 图集必须能按 manifest 切回帧
   并与烘焙逐像素一致（导出器自带往返测试）。

## 制作流程（顺序不能颠倒）

1. 定风格样本：分辨率、角色占屏比例、描边、材质色阶、玩家/危险/背景优先级。
2. 复制最近的模板配方（`examples/recipes/`，五类模板参数见
   `docs/recipe-guide.md`），先做一个代表性资产，不要先铺量。
3. `validate` → `bake --bmp --scale 4` 出图 → 画廊看 1 倍与 4 倍、深浅背景、
   剪影与灰度。**先修轮廓与比例，再加高光与纹理。**
4. 动作资产必看：剪辑播放 + 连续条（`bake --bmp` 的 `clip_*.bmp`），
   检查双脚接地、身体起伏、附件点跟随。
5. 放回场景：`examples/canvas-slice/`（浏览器）或 `examples/godot/`（Godot），
   在日夜背景下确认可读性。
6. 每轮只改一类问题；保留同种子同帧的前后对照，不用新截图覆盖旧基线。

## 视觉诊断路径

症状 → 优先检查（详见 `reference/visual-diagnosis.md`，含四个植入故障的实景演练）：

| 症状 | 先查 | 不要先做 |
|---|---|---|
| 看不出是什么 | 剪影、头身比例、识别特征 | 加随机纹理 |
| 跑步像滑行 | 接地帧、相位、腿角、连续条 | 加帧数掩盖 |
| 武器像脱手 | 肩/握点/枪口共用坐标（附件点叠加） | 手调每帧 |
| 夜里找不到关键物 | 夜间场景背景 + 对比视图、明度差 | 整屏加亮 |
| 烘焙报越界 | 帧约束（放大帧/改数据），诊断计数定位 | 无注释的 clip:'warn' |
| 每轮截图都不同 | 固定种子、固定帧、URL 视图状态 | 凭记忆比较 |

## 验收标准

- `node --test` 全过；`export` 往返（图集切回帧逐像素一致）通过。
- 画廊审图：轮廓/比例/动作/附件/配色/场景可读性逐项人工确认，
  无阻断项（关键部件裁掉、朝向错误、危险物不可辨、动画跳位、附件脱离）。
- 消费验证：Canvas 或 Godot 样例中锚点贴地、附件点正确、动画时长正确。
- 派生产物不写开发机绝对路径；清单无构建时间戳。

## 版本与回滚

技能与工具包版本绑定（见 `assets/toolkit/package.json` 的 version 与
`assets/toolkit/.pga-release.json` 的哈希清单）。安装脚本在安装前备份旧版；
回滚 = 将备份目录改回原名（见 `scripts/install.mjs --help`）。

旧版 `reference/pixel-art.md` 的伪代码骨架已被可运行工具包取代，不再随附；
如需历史对照，从安装备份中取回。
