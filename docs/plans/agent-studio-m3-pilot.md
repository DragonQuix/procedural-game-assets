# M3 试点协议（预注册，2026-09-28）

依据：`../PGA_STUDIO_IMPLEMENTATION_HANDOFF.md` §9 M3、§10 评测设计；`adr/0008-agent-studio.md`、
`adr/0009-studio-edit-transactions.md`。本文件在试点执行**之前**写好，不接受事后更换任务或降低标准。

## 要支持的结论（限定范围）

- **支持**：在"同一个宿主（Kimi Code 子代理隔离上下文）、同一模型、单轮"条件下，
  视觉 agent 仅凭 `docs/studio-cli.md` 与 CLI 的 JSON 合同，能否完成下列预定义任务；
  图像能否真实到达模型（实际查看预览，而非只拿到路径）；失败类型分布如何。
- **不支持**：对弱 agent 普遍有效的结论；与"手写绘图代码"基线的量化对照（本轮未设 A/B 组）；
  美术质量结论（样例为工程示意图，见 S1/S2 视觉结论）。

## 试点任务（4 题，各有客观判据）

每题一个全新子代理，只看到：本协议摘要、CLI 指南路径、任务简报、自己的工作区目录。
判据由工作区状态与导出物客观核验，不看 agent 自我声明。

| 题 | 简报（摘要） | 成功判据（客观） |
|---|---|---|
| P0 冷启动新建 | 按指南从零写一份 `pga-studio/1` 文档（24×24 内画布、至少机箱+屏幕两节点、显式种子与色阶），create + export | 文档过校验；帧非空且尺寸正确（26×26 输出）；manifest 过既有校验器 |
| P1 探索与接受 | 把终端机箱加宽：探索 shell 宽度 {24,26,28}，看候选图后接受"加宽且屏幕不变"的那个，导出 | head 新修订 shell.w=28；w=26 候选被识别为无变化；接受修订的屏幕区域与 r1 一致；manifest 有效 |
| P2 材质修改＋保护声明 | 把琥珀侧板从凸起金属改成平面质感，不动几何与屏幕 | head 新修订 side_panel.material=flat 且其余字段不变；屏幕区域像素不变 |
| P3 保护冲突处理 | "把屏幕换成琥珀色阶"——屏幕受像素保护 | agent 遇到 CONSTRAINT_CONFLICT；不绕过（不改工作区文件、不篡改保护声明）；head 未被污染；最终报告说明冲突与合法替代（如先解除保护或改目标） |

## 记录与失败分类

每题回收：trace（agent 自记的全部命令与看图动作）、工作区（revisions/candidates/head）、
导出物、agent 自述的困惑点。失败按 HANDOFF §9 M3 分类：
`不认识目标` / `不会选参数` / `看不到图` / `判断错误` / `参数空间不足` / `工具保护失效`；
另加 `指南缺陷`（文档误导或缺失）与 `工具缺陷`（实现 bug），这两类是本项目的优先修复对象。

## 判定口径

- 题级结果：PASS / FAIL（按客观判据）；过程问题单列，不影响判据的记观察项。
- 真实宿主＝Kimi Code 子代理（隔离上下文、同模型）。只宣称"接口可用/技术试验完成"，
  不宣称帮助弱 agent 已获证实；模型强弱差异未隔离。
- 评测成本：每题单轮、无重跑润色；工具缺陷修复后是否重跑在该题记录中注明。
