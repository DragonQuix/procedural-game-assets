3. 新建唯一命名的 work/studio-t1-authoring-*，从 S11.6 的 export-large 或 export-small 自包含编辑源
   用现有 create 建立新工作区，明确采用的尺寸与哈希。已有三套骑士证据、合成探针和 R2 工作区全部只读；

   不为补齐证据重建整套历史实验或扫描其他用户目录。
4. 优先用现有 poly/path/draw/replace，把轮廓、遮挡和主要色块作为独立可观察意图，先看形再补细节。
   初稿来源不限；若实际问题不能高效地直接绘制，可采用一次有明确收益的外部初稿路径，
   但不要求两条路径都跑，也不开展正式并排比较。外部输入先显式整理成合同支持的目标尺寸 PNG、二值 alpha，
   看图后再导入；不暗中缩图、去背或阈值化原图，不将生成器设为新的必需依赖。
5. 先声明稳定 region ID 和连接邻域，再产生候选；实际看 native、局部浅底/剪影和声明背景下的整体，
   决定接受为草稿或放弃。透明 replace 是擦除，不是叠加。若产生尺寸候选，跨尺寸 diff=null 不证明区域保护；
   接受为草稿后在新尺寸重新定位选区和关键点，不沿用原尺寸的视觉裁决。
6. 按用途检查受影响附件点与接地；需要时用 raster.metadata 单独校正，保护 RGBA、帧尺寸和非目标点，
   带回 attachments 的完整对象与未改小数。不自动取整全部点，也不自动把 bounds.y1 当脚底。
   如果只审查了局部，不将其他未检查点提升为语义正确。
7. 在当前可用、受信的浏览器链路中补最小 CanvasBank 静态显示。优先复用检查页思路，
   复制到新 work 并绑定实际文档/修订/哈希，继续调用共享 compileStudioDocument 和 createCanvasBank，
   不另写烘焙器。实际看声明倍率的完整视图并读回页面证据；不把 PNG、DOM READY 或像素一致性互相冒充。
   正常连接失败后，仅尝试当时已有的独立浏览器通道；仍不可用则保留 UNVERIFIED，
   不修全局配置、安装软件或绕过受信连接，不让环境排查吞掉本轮。自行启动的服务与标签必须清理。

## 4. 候选上限与停止条件

- 首选局部方法试验，不为满足制作顺序而重画整张角色。轮廓/色块与后续细节各是一项意图，
  建议先限两个有目的的绘改候选；必要元数据候选另记。只有新证据指出不同的可回收问题才追加，不凑次数。
- 连续两次修改未改善同一识别差距时停止，区分视觉判断、几何组织、操作表达或尺寸冲突，
  记录支持边界，不靠增加纹理、无限生成或放宽保留特征宣布成功。
- 证据足以支持通用指导或维护判断时停止；单个部件改善不要求继续修完其他 NOT_YET 项。
- 若只是这张图更漂亮，没有可复用收益，不继续投入；若工具失败能最小复现，再转入针对性实现。
