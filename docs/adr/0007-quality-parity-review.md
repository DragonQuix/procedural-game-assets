# ADR-0007：质量同级评审与循环合同 v2

日期：2026-09-28。状态：已接受。补充 ADR-0006，替代其 `pga-loop/1` 作为新任务合同。

## 背景

用户要求生成资产达到标杆的美术等级，但不制作其复制品。旧模板的身份支柱容易把质量
比较变成外观比较，逐项打分也不能独立证明整体美学达标。只有修改任务书而不改变机器
校验，会让缺少整体结论或漏评范围的报告仍能通过记录检查。

## 决定

1. 采用 `pga-loop/2`：质量标尺、用户明确约束、原创空间和必审范围分别记录。
   每个范围含基础设计、层级、完成度、使用四维，类型要求追加系列/动态/拼接维度。
   静态标杆支持的形色比较与独立动作/使用要求分开，不从参考臆造缺失标准。
2. visual 独立输出整体美学、整体质量等级、全部支柱、视图覆盖与明确约束结论。
   等级 `ON_PAR / ABOVE` 才满足同级，视觉分数仅诊断；交付 minimum 判分保留。
   无重大问题不自动等于好看，整体否决也必须有可见依据，不能因原创差异或个人口味否决。
3. 盲比先观察整体，再把质量等级与偏好分开；来源猜测改为可选。保持先封存后揭盲、
   同一 visual 上下文完成两阶段、两个全新完整批次通过以及指令级材料约束。
4. 旧合同与报告不自动迁移。新包提供从旧校验器提取的只读 `tools/legacy/asset-loop-v1.mjs`，
   仅验证历史记录；结果明确标记 v1，不代表达到新标准。升级任务重新确认宪章、冻结新
   候选并重评，旧 WOW 不能继承。
5. 美学通用准则维护在 `docs/visual-quality.md`，循环专属范围/合同写入技能 references。
   普通版保持其轻量验收，不继承长循环要求。本次只重建循环版载荷，不改既有普通版发行。

## 取舍与验证边界

- 新结构增加范围登记与报告成本，换取对整体结论和漏评的明确检查；不追求通用审美评分器。
- 旧验证器形成小份兼容代码，仅保留读取与判断，不在其中新增流程能力；固定的旧版
  合成记录验证兼容性和只读性，不能将合成裁决当真实 WOW。
- 机器只能检查文件、必填内容、枚举、覆盖、裁决一致性与哈希。不能证明图像真正同级、
  评审者真实观看/播放或材料约束未被违反，这些仍由独立执行与证据核查负责。
- 不改变 ADR-0001 的核心/IO 分层、ADR-0004 的共享烘焙或 ADR-0005 的模板边界。
