# ADR-0010：Studio 风格与构造——版本化词汇、局部覆盖与有限体积概括

日期：2026-09-28。状态：已接受（M4 范围）。

## 背景

M1–M3 验证了"文档 → 渲染 → 编辑事务 → 导出"闭环，但词汇只有矩形
（panel/screen × flat/bevel-metal/scanlines），所有资产都是盒子造型；
改色只能靠共享色阶引用（换色影响所有同色部件）；风格没有来源与焦点约定。
按 `docs/PGA_STUDIO_IMPLEMENTATION_HANDOFF.md` M4 与 §8.3，需要：
风格版本与许可、局部覆盖、第二种结构明显不同的资产、真正的体积/材质概括、
留出组合检验——且风格包不是单一模板换色器。

## 决定

1. **模式版本化：`pga-studio/1` 冻结，`pga-studio/2` 扩展**。校验器同时接受两者，
   词汇按版本隔离（/1 文档拒绝 poly/disc/局部覆盖/style.meta/shade-diag）。
   /1 渲染行为冻结并有 renderHash 回归锚点（`f645726c:6cebd809`）。
   随机命名空间 `studio/1:` 跨模式版本稳定（种子合同独立于模式版本）。
2. **新增有限几何**：`poly`（3–8 个整数顶点的单环多边形，可凹，经既有
   `PixelPainter.poly` 偶奇填充）与 `disc`（整数 cx/cy/rx/ry，经既有 `ellipse`）。
   几何字段按类型隔离（poly 不得含 x/y/w/h 等）。节点声明包围盒 = 顶点/半径 bbox，
   影响区域、遮挡与保护检查复用同一 bbox 与既有支持掩码机制。
3. **新增有限材质 `shade-diag`**（panel/poly/disc 可用）：在节点自身包围盒上按对角
   参数分带（高光/受光/基色/阴影），只改已有不透明像素。这是**风格化体积概括**，
   不是物理光照；形状为斜带时极端带可自然缺省，不制造杂点凑细节。
4. **色阶局部覆盖（写时复制）**：节点 `ramp` 可为 `{ shades:[4色] }`，只作用于该节点；
   共享色阶与其他节点不受影响（渲染层：同值局部覆盖与共享引用逐像素一致，有测试锚点）。
   `ramp.set` 操作同时接受共享名与局部覆盖两种取值。
5. **风格包元数据 `style.meta`**（/2，可选）：`license`/`source`/`focusRamp`/`notes`，
   白名单 + 长度上限，focusRamp 必须是已声明色阶；参与 styleHash。
   比例/细节尺度建议、正反例库、构造件库本轮**未做**（如实记录）。
6. **保护语义保持保守**：像素保护区域 = 节点最终帧 bbox（含透明角）；
   下层变化透过透明角改变区域内像素同样命中。指南如实说明该语义与"保护目标应与
   影响区域匹配"的使用约束（H2 试点实证）。
7. **M4 验收方式**：样例扳手（poly 手柄/钳口 + disc 螺栓 + shade-diag，共享钢铁/琥珀
   风格）与终端轮廓/构造明显不同、不是换色；再用两个留出组合的隔离 agent 试点
   （未见的 disc+panel+poly 仪表新建、poly 顶点缩短编辑）检验，不写进模板参数。

## 后果

- 同一版本化风格包下，箱体终端与非箱体式扳手/仪表同时成立（轮廓、构造、功能标识不同）。
- 过窄 poly（某方向 < 1px）栅格化丢像素为已知边界，已在指南记录并以
  `opaquePixels`/`frameBounds` 暴露给 agent 自查。
- 后续新增几何/材质必须走同一版本化词汇与绘制算子表，不得绕过校验。

## 备选方案（已否决）

- **直接扩写 /1 词汇不升版本**：旧校验器会静默接受新词汇，违背"未知即拒绝"的版本合同。
- **局部改色通过改共享色阶实现**：会改动同色的全部节点/资产（HANDOFF 明文禁止）。
- **shade-diag 按形状真实法线着色**：超出有限规则范围，变成伪物理光照；
  对角分带是如实声明的风格化概括。
- **像素保护区域改为节点自身不透明掩码**：会放过"透过透明角的可见变化"，
  保守 bbox 语义与 HANDOFF §7.4 的"结构没变 ≠ 画面没被遮挡"一致。
